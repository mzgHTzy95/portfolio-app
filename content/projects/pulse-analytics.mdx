## Overview

Pulse is a privacy-first product analytics platform that tracks user behavior without cookies or personal data. It renders real-time funnels, retention charts, and session replays from anonymized event streams.

## Problem

Most analytics tools require invasive tracking, GDPR consent banners, and heavy client-side scripts that hurt page performance. Teams wanted actionable insights without the privacy overhead.

## Solution

Pulse uses a lightweight edge-collected beacon (under 1KB) that records only anonymous events. The ingestion pipeline batches events into ClickHouse for sub-second funnel queries, and the dashboard renders with server components.

### Event ingestion

```typescript title="ingest.ts"
export async function POST(req: Request) {
  const event = await req.json();
  await clickhouse.insert({
    table: "events",
    values: [{ ...event, ts: new Date() }],
    format: "JSONEachRow",
  });
  return new Response("ok", { status: 202 });
}
```

## Tech Stack

- **Next.js** — Server components, route handlers
- **ClickHouse** — Sub-second funnel aggregation
- **PostgreSQL** — Account and project metadata
- **TailwindCSS** — Dashboard UI

## Key Features
