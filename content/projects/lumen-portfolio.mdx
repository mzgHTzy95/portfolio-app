## Overview

Lumen is a minimalist portfolio template designed for developers who want to showcase projects as detailed case studies alongside a writing practice.

## Problem

Most portfolio templates reduce projects to a card with a screenshot and a link, hiding the actual engineering decisions behind the work.

## Solution

Lumen treats each project as a full MDX case study with sections for problem, solution, and tech stack, rendered with syntax-highlighted code and a typography layer.

## Tech Stack

- **Next.js** — Static generation for MDX
- **MDX** — Case study authoring
- **TailwindCSS** — Typography plugin
- **Motion** — Page transitions

## Key Features

- MDX case studies with code highlighting
- Built-in blog with tags
- Dark mode by default
- SEO metadata per page
